## 为什么一张正常的卡，偏偏在 Claude 这里被拒

Anthropic 的收款走的是 Stripe。Stripe 对 AI 订阅这类「即买即用」的虚拟商品风控极严——这类服务盗刷和信用卡测试攻击太常见，所以它把安全阈值设得非常高。你的卡在别处能用，只说明银行这边没问题，不代表能过 Stripe 这一关。

具体来说，风控主要看四层东西。

### 第一层：发卡地区

Stripe 判断一张卡的风险，先看卡号开头的 BIN 码，也就是发卡行信息。国内银行发行的 Visa、Mastercard，BIN 一查就是中国大陆发卡行，会被直接按高风险处理。Anthropic 的帮助文档里也写得很直白：建议使用非中国内地发行的信用卡。

这解释了一个常见疑惑：为什么全币卡、双币卡也过不去。卡的「币种」和「发卡地区」是两回事，Stripe 看的是后者。目前 Anthropic 的支持地区列表里没有中国大陆，所以这一层基本没有商量余地。

### 第二层：IP 和账单地址对不上

这是国际用户被拒的头号原因。Stripe 会对比三样东西：付款时的 IP 所在地、卡上填的账单地址、卡的发卡国家，三者在地理上应该基本一致。

典型的翻车场景：用代理从美国 IP 访问 Claude，付款却用一张中国内地卡、填着国内地址。在风控算法眼里，这和盗刷几乎是同一个画像，直接拦截。这也是为什么很多人换了浏览器、清了 Cookie 还是没有用——问题根本不在浏览器。

### 第三层：3DS 验证被浏览器挡住了

不少银行对国际数字商品交易要求 3D Secure 验证，也就是短信验证码或在银行 App 里点确认。如果你的浏览器开了广告拦截插件，3DS 弹窗可能根本加载不出来，交易就会自动失败。这种情况下卡本身没问题，换个无痕窗口、关掉拦截插件再试就行。

### 第四层：反复重试，把自己试进了黑名单

被拒之后连点几次「retry payment」，Stripe 会把这种高频失败判定为可疑行为，临时拉黑你的卡甚至 IP。所以被拒之后最不该做的事就是连续重试。一般建议等 24 小时，期间把其他问题修好。

## 这几种情况，其实不是卡的问题

**扣了钱但订阅没开通。** 提交卡片后，Stripe 会先向银行发起预授权，确认卡里有没有钱。银行把这笔资金挂起来，看起来像扣款；但如果交易没通过风控，实际支付会被取消，挂起的资金几个工作日内退回，多数银行在 3 到 7 天内到账。钱没丢，只是慢。

**订阅卡在 past due，又显示有 active subscription。** 这是 Anthropic 订阅系统的状态异常：系统同时认为你有订阅，又不让你用，俗称「僵尸态」。换卡、换浏览器都没用，只能去 Anthropic 帮助中心提工单，让客服手动重置，处理周期一般 5 到 10 个工作日。

**手机上订阅了 Pro，Claude Code 还是 Free。** 走 App Store 内购的 Pro 和走 Stripe 的网页订阅完全是两套计费体系，互不相通。而且 App 内购开通的 Pro 不包含 Claude Code 的使用权限——想用 Claude Code，必须走网页端绑卡这条路。

**想用 PayPal 付款。** 目前 Anthropic 不支持 PayPal，只能用支持的银行卡或虚拟卡走 Stripe，或者走 App 内购。

## 按这个顺序排查，别乱试

结合上面的原因，推荐按下面的顺序处理：

1. **先停手。** 被拒后至少等 24 小时，避免触发高频失败的风控。
2. **对齐 IP 和账单地址。** 确保付款时的 IP 定位国家和卡的账单地址一致，代理建议开全局模式。
3. **检查支付环境。** 用无痕窗口，关掉广告拦截插件，确认 3DS 弹窗能正常弹出。
4. **核对账单信息。** 姓名、地址、邮编要和银行预留信息完全一致，邮编错一位都可能触发 AVS 校验失败。
5. **确认卡的条件。** 余额要够——Claude Pro 月费 20 美元，卡里至少留出这个数；单笔限额不能太低，卡要开通国际美元扣款。

五步走完还是被拒，那基本可以断定问题出在卡本身：发卡地区过不了 BIN 检查。这时候该考虑换卡了。

## 订阅成功之后，注意这几件小事

- **别用同一张卡给多个账号订阅。** Anthropic 和 OpenAI 对一卡多号的识别越来越准，一旦被判定为代购行为，账号和卡都可能被停用。一张卡绑一个账号最稳。
- **留意卡内余额。** 续费时余额不足导致扣款失败，同样会给卡留下失败记录。可以在订阅平台关闭自动续费，每月手动续。
- **少试错。** 每次支付失败都会留下记录，失败次数多了卡会被标记。有问题先排查原因，别拿卡去反复撞。

## 几个常见问题

**被拒之后要等多久再试？**

至少 24 小时。这期间检查 IP、账单地址和浏览器设置，等这些都对齐了再试。连续快速重试只会把卡推近黑名单。

**用虚拟卡就一定能成功吗？**

没人能打包票。Stripe 会持续更新 BIN 黑名单，个别卡段偶尔会被临时标记。不过美区 BIN 的卡已经避开了国内用户最常见的拦截原因，成功率远高于直接刷国内卡。真遇到卡段被标记，联系平台换一个卡段通常就能解决。

**手机 App 订阅是不是更稳？**

是另一条路，但要想清楚：App 内购走的是 Apple 的计费体系，确实绕开了 Stripe 的网页风控，前提是美区 Apple ID。但前面说过，这条路开通的 Pro 用不了 Claude Code。如果你只是在网页和手机上聊天，可以考虑；要写代码，还是得网页绑卡。
